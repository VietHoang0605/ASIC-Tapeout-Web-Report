1 Làm quen tools 
1.1 Giao diện app
Mục tiêu ở phần này là nắm được phần hiển thị của app.
Giao diện app gồm 3 khu vực như được tô màu ở trên gồm:
- Các chức năng của app:
•
Setup: chọn design, PDK, SCL, constraints và preflight. 
•
RTL IDE: sửa RTL, lint, mô phỏng, xem waveform. 
•
Pipeline: xem các bước RTL → GDS và log trực tiếp. 
•
Runs: lịch sử run, trạng thái pass/fail, tải bundle. 
•
Preview: xem hình layout, GDS, DEF, netlist và file đầu ra. 
•
Analytics: xem metric của từng công đoạn. 
•
Verify: DRC, LVS, timing, antenna và XOR. 
•
DSE: chạy nhiều cấu hình để so sánh. 
•
Layout: mở bằng KLayout, Magic hoặc GDS3D. 
•
Tools: quản lý Docker/Podman, LibreLane image và PDK. 
•
Manual: xem và chạy lệnh LibreLane tương ứng. 
•
Cells & Macros: standard cell, custom cell và hard macro.
Trong lab 0 này, ta chỉ sử dụng: Tools → Setup → Pipeline → Runs → Preview → Verify.

'
sudo docker exec ctwsemi sh -lc '
iverilog -V | head -n 1
command -v vvp
'
sudo docker restart ctwsemi

 Giải thích Cấu hình cho counter hiện tại như sau:
- “DESIGN_NAME”: “counter” tên của module cần chạy gds, module này gọi là module top.
- “VERILOG_FILES” nơi chứa file RTL (file có đuôi .v).
- “CLOCK_PORT”: tên của chân tín hiệu clock, với ví dụ này là “clk”.
- “CLOCK_PERIOD”: chu kì của clock, đơn vị ns, với ví dụ này là 10ns (100MHz).
-“PDK”: thư viện công nghệ dùng, với ví dụ này là sky130A.
Các cấu hình khác như diện tích của die chip, diện tích core, mật độ phân bổ, ta để mặc định.
Làm các bước theo thứ tự đánh số như hình dưới.
